# youknowans.com

A photography portfolio built with [Astro](https://astro.build) and served from Cloudflare. Astro runs only on your computer (or a build server) and turns the files in `src/` into plain HTML, CSS and a little JavaScript. Visitors get a fully static site: no server code, no third-party scripts.

## Layout

```
src/                 what you edit
  layouts/Base.astro   the shared page shell: head, nav, footer (edit once, every page updates)
  pages/               one file per page: index (Portfolio), journal, contact, 404
  pages/posts/[id].astro  the design every journal post uses
  content/journal/     journal posts, one Markdown (.md) file each
public/              copied into the site unchanged
  _headers             security headers (see SECURITY.md)
  css/  js/  images/   styles, browser scripts, web-sized photos
  js/photos.js         GENERATED by optimise-images.py, do not edit
dist/                the finished site Astro builds (git-ignored, this is what is published)
images/full/         your original exports (stays on your computer, git-ignored)
optimise-images.py   makes web photos and photos.js from your Lightroom exports
astro.config.mjs     Astro settings
wrangler.jsonc       tells Cloudflare what to publish (dist/) and on which domains
SECURITY.md          what is protected, and your checklist
MANUAL.md            how to do everyday jobs
```

## Commands

```
npm install          # once, and after updating package.json
npm run dev          # write and preview: http://localhost:4321, refreshes as you save, shows drafts
npm run build        # make the finished site in dist/
npm run preview      # build, then serve it exactly as Cloudflare will (security headers on): http://localhost:8787
npm run deploy       # build and publish by hand
```

## Publish

`git push` to `main`. In Cloudflare (Workers & Pages, your project, Settings, Build) the build command must be `npm run build` and the deploy command `npx wrangler deploy`.
