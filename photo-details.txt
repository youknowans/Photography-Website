# Photo details: captions, places and keywords typed by hand.
#
# One photo per line, four parts separated by the | character:
#     name | caption | place | keywords
#
#   name      the photo's filename, without .jpg (capitals do not matter)
#   caption   a short description of what is in the picture. Screen readers read
#             it aloud, and it shows under the photo when it is opened. No | inside it.
#   place     City, Country  (shows in the lightbox)
#   keywords  separated by commas. Each keyword becomes a filter tab on the Portfolio
#             page, e.g.  travel, street. A photo can have several.
#
# A part you leave empty is not changed. Text here wins over what is stored inside the
# photo file. Lines starting with # are ignored. After editing, run
#     python optimise-images.py
# and the changes appear in the gallery.
#
